# Neural Network Implementations

A collection of Neural Network models and deep learning experiments implemented using Python and popular machine learning frameworks. This repository covers fundamental and advanced concepts of Artificial Neural Networks, including perceptrons, multi-layer networks, convolutional neural networks, recurrent neural networks, and transfer learning techniques.

## Implementations

* Perceptron Learning Algorithm
* Multi-Layer Perceptron (MLP)
* Backpropagation Neural Network using TensorFlow
* Hyperparameter Tuning for Neural Networks
* Convolutional Neural Network (CNN) using Keras
* Recurrent Neural Network (RNN) using PyTorch
  

## Technologies Used

* Python
* NumPy
* TensorFlow
* Keras
* PyTorch
* Matplotlib
* Jupyter Notebook
